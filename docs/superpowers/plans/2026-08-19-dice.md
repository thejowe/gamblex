# Dice (Plan 8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir el módulo Dice (umbral 1-99 configurable, dirección mayor/menor, RNG del host, margen de casa 1%) como mesa multijugador más en `CasinoFloor`, y con él fijar el patrón de **ronda independiente por jugador** (sin asientos, sin turnos) que Crash/Mines/Plinko replicarán tal cual.

**Architecture:** `DiceRoller` (lógica pura, RNG inyectable en tests, análoga a `RouletteWheel`) genera el número 0-100 del host. `DiceTableState` (lógica pura, vive solo en el host, análoga a `BlackjackTableState`/`RouletteTableState` pero **sin asientos**: un `Dictionary` `players` indexado por `player_id`, cada jugador se crea perezosamente en su primera tirada) valida umbral/dirección/apuesta, resuelve la tirada contra `ChipLedger` y emite `chips_won` igual que Blackjack. `DiceTableController` (nodo de red, mismo patrón host-autoridad que `TableController`/`RouletteTableController`) recibe la tirada del cliente por RPC, la aplica sobre `DiceTableState` y retransmite el estado resultante — con broadcast a **todos** los presentes en `CasinoFloor`, no solo al jugador que tiró, para que se vea en vivo. La escena `DiceTableNet` aloja la mesa y se añade a `CasinoFloor` en su propia franja vertical, debajo de Póker.

Este es el Plan base de la "Ampliación v1.1" (Dice/Crash/Mines/Plinko): la sección **"Patrón de ronda independiente para Crash/Mines/Plinko"** al final de este documento fija los nombres exactos que los tres agentes siguientes deben reutilizar sin inventar los suyos.

**Tech Stack:** Godot 4.4+, GDScript, GUT (lógica de `DiceRoller`/`DiceTableState`, sin red), `MultiplayerAPI`/RPCs nativos de Godot sobre el `SteamMultiplayerPeer` ya operativo (Plan 2/3).

**Spec:** `docs/superpowers/specs/2026-08-17-casino-multiplayer-design.md` (sección "Ampliación v1.1", subsecciones "Componente nuevo: patrón de ronda independiente" y "Dice")

## Global Constraints

- No se toca `scripts/net/table_controller.gd`, `scripts/net/roulette_table_controller.gd`, `scripts/net/poker_table_controller.gd`, `scripts/net/battle_controller.gd` ni sus escenas — Dice añade sus propias clases y escenas paralelas.
- Servidor autoritativo: toda decisión de juego (tirada, validación, pago) ocurre solo en el host (`multiplayer.is_server()`); los clientes solo envían intención y reciben estado.
- El servidor tiene siempre `unique_id == 1` — los clientes dirigen sus RPCs de acción con `rpc_id(1, ...)`.
- Gotcha ya resuelto en Plan 3, replicar el mismo patrón: `rpc_id(1, ...)` con modo `call_remote` falla si quien llama ya es el peer 1 (el host actuando sobre su propia mesa). `DiceTableController` expone un método wrapper (`roll`) que en el host aplica la acción directamente al estado en vez de auto-llamarse por RPC; los clientes sí pasan por la RPC `request_roll`.
- Gotcha de layout ya arreglado en Ruleta (commit `cb50b8e`): los botones usan offsets absolutos en píxeles, no encogen con el contenedor — dimensionar cada botón al ancho real de su texto en español, no reutilizar 120px por defecto.
- **Sin asientos.** A diferencia de Blackjack/Ruleta/Póker, Dice no tiene `SEAT_COUNT` ni `sit()`. El estado por jugador se crea perezosamente la primera vez que ese `player_id` tira — no hace falta una acción de "unirse" separada.
- `win_chance = 100 - umbral` (dirección "mayor que") o `= umbral` (dirección "menor que"). `multiplicador = 99 / win_chance` (el 1% de margen ya está incorporado en el 99). Fórmulas exactas de la spec, no se recalculan de otra forma.
- Umbral válido: entero 1-99 inclusive (deja `win_chance` siempre en el rango (0, 100), evita división por cero).
- Balance inicial por jugador: 500 fichas, igual que el resto de mesas (`ChipLedger.new(500)`).
- Sin persistencia entre partidas — el estado de la mesa vive solo en memoria del host mientras dura la sesión.

```gdscript
class_name DiceTableState
extends RefCounted

signal chips_won(player_id: int, amount: int)

const STARTING_BALANCE := 500

enum Direction { OVER, UNDER }

class Player:
    var player_id: int = 0
    var ledger: ChipLedger
    var last_round: Dictionary = {}

var players: Dictionary = {}
var roller: DiceRoller

func _init(p_roller: DiceRoller = null) -> void:
    roller = p_roller if p_roller else DiceRoller.new()

static func win_chance(threshold: int, direction: int) -> float:
    if direction == Direction.OVER:
        return 100.0 - threshold
    return float(threshold)

static func multiplier(threshold: int, direction: int) -> float:
    return 99.0 / win_chance(threshold, direction)

func _player_for(player_id: int) -> Player:
    if not players.has(player_id):
        var player := Player.new()
        player.player_id = player_id
        player.ledger = ChipLedger.new(STARTING_BALANCE)
        players[player_id] = player
    return players[player_id]
```

```gdscript
func roll(player_id: int, threshold: int, direction: int, amount: int) -> bool:
    if threshold < 1 or threshold > 99:
        return false
    if direction != Direction.OVER and direction != Direction.UNDER:
        return false
    var player := _player_for(player_id)
    if not player.ledger.place_bet(amount):
        return false
    var result := roller.roll()
    var win := (direction == Direction.OVER and result > threshold) \
        or (direction == Direction.UNDER and result < threshold)
    var payout := 0
    if win:
        payout = int(amount * multiplier(threshold, direction))
        player.ledger.payout(payout)
        chips_won.emit(player_id, payout - amount)
    player.last_round = {
        "threshold": threshold,
        "direction": direction,
        "amount": amount,
        "result": result,
        "win": win,
        "payout": payout,
    }
    return true

func to_dict() -> Dictionary:
    var players_data := {}
    for player_id in players:
        var player = players[player_id]
        players_data[player_id] = {
            "player_id": player.player_id,
            "balance": player.ledger.balance,
            "last_round": player.last_round,
        }
    return {"players": players_data}
```

- [x] **Step 1: Implementar DiceTableController**

```gdscript
class_name DiceTableController
extends Node

signal state_changed(state: Dictionary)
signal chips_won(player_id: int, amount: int)

var table_state: DiceTableState

func _ready() -> void:
    if multiplayer.is_server():
        table_state = DiceTableState.new()
        table_state.chips_won.connect(_on_table_chips_won)

# Puntos de entrada para la UI local (host o cliente). El host actúa directo
# sobre table_state; un rpc_id(1, ...) a sí mismo lo rechaza el MultiplayerAPI
# ("call_remote" no permite invocarse a uno mismo), así que el host no puede
# pasar por las RPCs request_* para sus propias acciones.
func roll(threshold: int, direction: int, amount: int) -> void:
    if multiplayer.is_server():
        _apply_roll(threshold, direction, amount, multiplayer.get_unique_id())
    else:
        request_roll.rpc_id(1, threshold, direction, amount)

# Un cliente que entra a la mesa después de que ya hubo tiradas no recibe
# nada por su cuenta: el host solo retransmite _receive_state cuando algo
# cambia, nunca al conectar (mismo gotcha que TableController.request_state
# en Plan 3). Sin este pedido explícito el cliente se queda con el estado en
# blanco para siempre.
func request_state() -> void:
    if multiplayer.is_server():
        return
    _request_state.rpc_id(1)

@rpc("any_peer", "call_remote", "reliable")
func _request_state() -> void:
    if not multiplayer.is_server():
        return
    _receive_state.rpc_id(multiplayer.get_remote_sender_id(), table_state.to_dict())

@rpc("any_peer", "call_remote", "reliable")
func request_roll(threshold: int, direction: int, amount: int) -> void:
    if not multiplayer.is_server():
        return
    _apply_roll(threshold, direction, amount, multiplayer.get_remote_sender_id())

func _apply_roll(threshold: int, direction: int, amount: int, player_id: int) -> void:
    if table_state.roll(player_id, threshold, direction, amount):
        _broadcast_state()

func _broadcast_state() -> void:
    _receive_state.rpc(table_state.to_dict())

# Broadcast a TODOS los presentes en CasinoFloor, no solo a quien tiró — la
# spec pide visibilidad compartida de las rondas de los demás aunque nadie
# más participe en ellas.
@rpc("authority", "call_local", "reliable")
func _receive_state(state: Dictionary) -> void:
    state_changed.emit(state)

func _on_table_chips_won(player_id: int, amount: int) -> void:
    chips_won.emit(player_id, amount)
```

Guardar en `scripts/net/dice_table_controller.gd`. Nota: en el host, `_ready()` crea `table_state` y conecta su `chips_won`; en los clientes queda `null` a propósito — los clientes nunca ejecutan lógica de juego, solo reciben `state_changed`/`chips_won` y piden acciones por RPC.

```gdscript
var _last_players: Dictionary = {}

func _display_name(peer_id: int) -> String:
	var steam_id: int = NetworkManager.peer_steam_ids.get(peer_id, 0)
	if steam_id == 0:
		return "jugador %d" % peer_id
	var persona_name := Steam.getFriendPersonaName(steam_id)
	return persona_name if not persona_name.is_empty() else "jugador %d" % peer_id

func _ready() -> void:
	table_controller.state_changed.connect(_on_state_changed)
	bet_over_button.pressed.connect(func(): _roll(DiceTableState.Direction.OVER))
	bet_under_button.pressed.connect(func(): _roll(DiceTableState.Direction.UNDER))
	NetworkManager.identities_changed.connect(_refresh_players_label)
	# Mismo gotcha que blackjack_table_net.gd/roulette_table_net.gd: un cliente
	# recién llegado a esta escena puede que aún no tenga el
	# SteamMultiplayerPeer en CONNECTED — bloquear las apuestas hasta entonces
	# evita el rpc_id() fallido.
	if not multiplayer.is_server():
		var peer := multiplayer.multiplayer_peer
		if peer == null or peer.get_connection_status() != MultiplayerPeer.CONNECTION_CONNECTED:
			bet_over_button.disabled = true
			bet_under_button.disabled = true
			multiplayer.connected_to_server.connect(func():
				bet_over_button.disabled = false
				bet_under_button.disabled = false
				table_controller.request_state()
			)
		else:
			table_controller.request_state()

func _roll(direction: int) -> void:
	table_controller.roll(int(threshold_spinbox.value), direction, int(amount_spinbox.value))

func _on_state_changed(state: Dictionary) -> void:
	_last_players = state["players"]
	_refresh_players_label()

func _refresh_players_label() -> void:
	if _last_players.is_empty():
		players_label.text = "Nadie ha tirado todavía."
		return
	var lines: Array[String] = []
	for player_id in _last_players:
		var player = _last_players[player_id]
		var line := "%s — fichas %d" % [_display_name(player["player_id"]), player["balance"]]
		var last_round = player["last_round"]
		if not last_round.is_empty():
			var direction_text := "mayor que" if last_round["direction"] == DiceTableState.Direction.OVER else "menor que"
			var outcome_text := "ganó" if last_round["win"] else "perdió"
			line += " — última tirada %.2f (umbral %d %s, %s)" % [
				last_round["result"], last_round["threshold"], direction_text, outcome_text
			]
		lines.append(line)
	players_label.text = "\n".join(lines)
```

## Patrón de ronda independiente para Crash/Mines/Plinko

Fijado aquí para que los Agentes 9/10/11 no tengan que inventarlo ni adivinar nombres. Replicar exactamente esta forma, sustituyendo "Dice" por el nombre del juego:

- **`<Juego>Roller`** (`scripts/<juego>/<juego>_roller.gd`, `RefCounted`): RNG del host con cola `results` inyectable para tests (mismo shape que `DiceRoller`/`RouletteWheel`). El tipo de `results` y lo que devuelve `roll()`/método equivalente depende del juego (float para Dice, punto de explosión para Crash, posiciones de minas para Mines, bits izquierda/derecha para Plinko).
- **`<Juego>TableState`** (`scripts/<juego>/<juego>_table_state.gd`, `RefCounted`): **sin `SEAT_COUNT` ni asientos.** Propiedad `players: Dictionary` (`player_id: int -> Player`), con una clase interna `Player` que como mínimo tiene `player_id: int` y `ledger: ChipLedger`. Un método privado `_player_for(player_id: int) -> Player` crea la entrada perezosamente (ledger a 500 fichas) la primera vez que ese jugador actúa — no existe un paso de "unirse" separado. Señal `chips_won(player_id: int, amount: int)` emitida con la **ganancia neta** (payout menos apuesta) solo cuando el jugador gana, igual que `BlackjackTableState`/`DiceTableState` — es lo que `CasinoFloor` conecta a la meta colectiva. Método `to_dict() -> Dictionary` con forma `{"players": {player_id: {...}}}`.
- **`<Juego>TableController`** (`scripts/net/<juego>_table_controller.gd`, `Node`): mismo wrapper host-vs-cliente que `TableController`/`RouletteTableController`/`DiceTableController` — los métodos públicos de entrada aplican la acción directo si `multiplayer.is_server()`, o hacen `rpc_id(1, ...)` si no. Señales `state_changed(state: Dictionary)` y `chips_won(player_id: int, amount: int)` (esta última reenvía la del `table_state`, conectada en `_ready()` solo en el host). `request_state()` + `_request_state`/`_receive_state` para clientes que entran tarde, idéntico a los tres controladores existentes.
- **Broadcast compartido:** `_broadcast_state()` hace `_receive_state.rpc(...)` (a **todos** los presentes, no solo al jugador que actuó) — la visibilidad en vivo de las rondas ajenas es parte de la spec, no opcional.
- **Integración en `CasinoFloor`:** cada agente añade su propia franja vertical en `casino_floor.tscn` (revisar qué rango de Y está libre antes de añadir la suya) y, en `scripts/net/casino_floor.gd`, un bucle `find_children("*", "<Juego>TableController", true, false)` junto a los ya existentes para conectar `chips_won` a `_on_chips_won` en modo libre.
