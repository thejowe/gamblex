# Mines (Plan 10) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir el módulo Mines (grid con minas ocultas, multiplicador progresivo por casilla revelada y cash-out) como mesa multijugador más en `CasinoFloor`, reutilizando tal cual el patrón de "ronda independiente por jugador" que dejó Plan 8 (Dice).

**Architecture:** `MinesRoller` (lógica pura, RNG inyectable en tests, análoga a `DiceRoller`) genera el conjunto de posiciones de minas del host. `MinesTableState` (lógica pura, vive solo en el host, análoga a `DiceTableState` pero con ronda multi-paso en vez de atómica: un jugador hace `start_round` → varios `reveal` → `cash_out` o game-over por mina) valida cada acción, resuelve contra `ChipLedger` y emite `chips_won` igual que Dice. A diferencia de Dice, el estado por jugador tiene una ronda **en curso** (`active_round`) además de la última ronda completada (`last_round`); `to_dict()` nunca incluye las posiciones de las minas mientras la ronda sigue activa — solo aparecen en `last_round` una vez terminada (mina revelada o cash-out). `MinesTableController` (nodo de red, mismo patrón host-autoridad que `DiceTableController`) expone tres acciones (`start_round`, `reveal`, `cash_out`) en vez de una sola, cada una con su propio wrapper host-vs-cliente y su propio RPC. La escena `MinesTableNet` aloja la mesa (grid de botones 5×5 + controles) y se añade a `CasinoFloor` en su propia franja vertical, debajo de Dice.

**Tech Stack:** Godot 4.4+, GDScript, GUT (lógica de `MinesRoller`/`MinesTableState`, sin red), `MultiplayerAPI`/RPCs nativos de Godot sobre el `SteamMultiplayerPeer` ya operativo (Plan 2/3).

**Spec:** `docs/superpowers/specs/2026-08-17-casino-multiplayer-design.md` (sección "Ampliación v1.1", subsección "Mines") y `docs/superpowers/plans/2026-08-19-dice.md` (sección final "Patrón de ronda independiente para Crash/Mines/Plinko", que fija los nombres que este plan reutiliza).

## Global Constraints

- No se toca `scripts/net/table_controller.gd`, `scripts/net/roulette_table_controller.gd`, `scripts/net/poker_table_controller.gd`, `scripts/net/battle_controller.gd` ni `scripts/net/dice_table_controller.gd` ni sus escenas — Mines añade sus propias clases y escenas paralelas.
- Servidor autoritativo: toda decisión de juego (posiciones de minas, validación, pago) ocurre solo en el host (`multiplayer.is_server()`); los clientes solo envían intención y reciben estado.
- El servidor tiene siempre `unique_id == 1` — los clientes dirigen sus RPCs de acción con `rpc_id(1, ...)`.
- Gotcha ya resuelto en Plan 3/8, replicar el mismo patrón: `rpc_id(1, ...)` con modo `call_remote` falla si quien llama ya es el peer 1 (el host actuando sobre su propia mesa). `MinesTableController` expone métodos wrapper (`start_round`, `reveal`, `cash_out`) que en el host aplican la acción directamente al estado en vez de auto-llamarse por RPC; los clientes sí pasan por las RPCs `request_*`.
- Gotcha de layout ya arreglado en Ruleta (commit `cb50b8e`): los botones usan offsets absolutos en píxeles, no encogen con el contenedor — dimensionar cada botón al ancho real de su texto en español, no reutilizar 120px por defecto.
- **Sin asientos.** Igual que Dice, Mines no tiene `SEAT_COUNT` ni `sit()`. El estado por jugador se crea perezosamente la primera vez que ese `player_id` empieza una ronda.
- Margen de casa: 1%, incorporado como factor `0.99` en la fórmula de multiplicador — no se aplica como un descuento aparte.
- Balance inicial por jugador: 500 fichas, igual que el resto de mesas (`ChipLedger.new(500)`).
- **Las posiciones de las minas nunca viajan al cliente mientras la ronda está activa.** `to_dict()` debe omitir la clave `mines` del `active_round` público — solo aparece dentro de `last_round` después de que la ronda termina (mina revelada o cash-out). Verificar esto con un test explícito, no solo con la UI.
- Sin persistencia entre partidas — el estado de la mesa vive solo en memoria del host mientras dura la sesión.

extends RefCounted

var results: Array = []

func roll(total_cells: int, mine_count: int) -> Array:
    if not results.is_empty():
        return results.pop_front()
    var positions: Array = range(total_cells)
    positions.shuffle()
    return positions.slice(0, mine_count)

```gdscript
class_name MinesTableState
extends RefCounted

signal chips_won(player_id: int, amount: int)

const STARTING_BALANCE := 500

class Player:
    var player_id: int = 0
    var ledger: ChipLedger
    var last_round: Dictionary = {}
    var active_round: Dictionary = {}

var players: Dictionary = {}
var roller: MinesRoller

func _init(p_roller: MinesRoller = null) -> void:
    roller = p_roller if p_roller else MinesRoller.new()

# Producto incremental (T-i)/(T-M-i) en vez de C(T,k)/C(T-M,k) con
# factoriales completos: evita overflow en grids grandes y es
# matemáticamente la misma razón combinatoria.
static func multiplier(total_cells: int, mine_count: int, revealed_count: int) -> float:
    var result := 1.0
    for i in range(revealed_count):
        result *= float(total_cells - i) / float(total_cells - mine_count - i)
    return 0.99 * result

func _player_for(player_id: int) -> Player:
    if not players.has(player_id):
        var player := Player.new()
        player.player_id = player_id
        player.ledger = ChipLedger.new(STARTING_BALANCE)
        players[player_id] = player
    return players[player_id]
```

## Task 3: MinesTableState — start_round, reveal, cash_out y to_dict sin fuga de minas

**Files:**
- Modify: `scripts/mines/mines_table_state.gd`
- Modify: `tests/unit/test_mines_table_state.gd`

**Interfaces:**
- Produce (añadido a `MinesTableState`):
  - `start_round(player_id: int, total_cells: int, mine_count: int, amount: int) -> bool` — valida `total_cells >= 2`, `1 <= mine_count < total_cells`, que no haya ya una ronda activa para ese jugador, y la apuesta contra el ledger (creándolo perezosamente); si todo es válido, tira las minas con `roller.roll(total_cells, mine_count)` y guarda `active_round = {"total_cells", "mine_count", "mines", "revealed": [], "amount", "multiplier": 1.0}`.
  - `reveal(player_id: int, index: int) -> bool` — valida que haya ronda activa, índice en rango y no revelado ya; si `index` está en `mines`, termina la ronda como derrota (sin pago); si es seguro, lo añade a `revealed` y recalcula `multiplier`; si con ese reveal se agotan todas las casillas seguras (`revealed.size() == total_cells - mine_count`), hace cash-out automático (paga y termina la ronda como victoria) porque ya no quedan casillas seguras por revelar.
  - `cash_out(player_id: int) -> bool` — valida que haya ronda activa y que `revealed` no esté vacío (no se puede cobrar sin haber revelado nada); paga `amount * multiplier` (truncado a entero) y termina la ronda como victoria.
  - `to_dict() -> Dictionary` — `{"players": {player_id: {"player_id", "balance", "active_round", "last_round"}}}`. `active_round` en el dict público es una copia de `player.active_round` **sin la clave `"mines"`** cuando hay ronda en curso, o `{}` si no la hay. `last_round` sí incluye `"mines"` completo, porque para cuando se llena ya terminó la ronda.

```gdscript
func start_round(player_id: int, total_cells: int, mine_count: int, amount: int) -> bool:
    if total_cells < 2:
        return false
    if mine_count < 1 or mine_count >= total_cells:
        return false
    var player := _player_for(player_id)
    if not player.active_round.is_empty():
        return false
    if not player.ledger.place_bet(amount):
        return false
    player.active_round = {
        "total_cells": total_cells,
        "mine_count": mine_count,
        "mines": roller.roll(total_cells, mine_count),
        "revealed": [],
        "amount": amount,
        "multiplier": 1.0,
    }
    return true

func reveal(player_id: int, index: int) -> bool:
    if not players.has(player_id):
        return false
    var player: Player = players[player_id]
    if player.active_round.is_empty():
        return false
    var round_data: Dictionary = player.active_round
    if index < 0 or index >= round_data["total_cells"]:
        return false
    if round_data["revealed"].has(index):
        return false
    if round_data["mines"].has(index):
        _end_round(player, round_data, false, 0)
        return true
    round_data["revealed"].append(index)
    round_data["multiplier"] = multiplier(round_data["total_cells"], round_data["mine_count"], round_data["revealed"].size())
    var safe_cells: int = round_data["total_cells"] - round_data["mine_count"]
    if round_data["revealed"].size() == safe_cells:
        var payout := int(round_data["amount"] * round_data["multiplier"])
        player.ledger.payout(payout)
        var amount: int = round_data["amount"]
        _end_round(player, round_data, true, payout)
        chips_won.emit(player_id, payout - amount)
    return true

func cash_out(player_id: int) -> bool:
    if not players.has(player_id):
        return false
    var player: Player = players[player_id]
    if player.active_round.is_empty():
        return false
    var round_data: Dictionary = player.active_round
    if round_data["revealed"].is_empty():
        return false
    var payout := int(round_data["amount"] * round_data["multiplier"])
    player.ledger.payout(payout)
    var amount: int = round_data["amount"]
    _end_round(player, round_data, true, payout)
    chips_won.emit(player_id, payout - amount)
    return true

func _end_round(player: Player, round_data: Dictionary, win: bool, payout: int) -> void:
    player.last_round = {
        "total_cells": round_data["total_cells"],
        "mine_count": round_data["mine_count"],
        "mines": round_data["mines"],
        "revealed": round_data["revealed"],
        "amount": round_data["amount"],
        "win": win,
        "payout": payout,
    }
    player.active_round = {}

func to_dict() -> Dictionary:
    var players_data := {}
    for player_id in players:
        var player: Player = players[player_id]
        var public_active := {}
        if not player.active_round.is_empty():
            public_active = player.active_round.duplicate()
            public_active.erase("mines")
        players_data[player_id] = {
            "player_id": player.player_id,
            "balance": player.ledger.balance,
            "active_round": public_active,
            "last_round": player.last_round,
        }
    return {"players": players_data}
```

Nota: la victoria por revelar todas las casillas seguras (`reveal` con auto-cash-out) es un caso borde que no está escrito literal en la spec pero es necesario — sin él, un jugador que revela todas las casillas seguras se queda en una ronda "activa" sin ninguna casilla segura por revelar y sin forma de progresar. Está cubierto por `test_reveal_all_safe_cells_auto_cashes_out_as_win`.

## Task 4: MinesTableController — puente de red sobre MinesTableState

**Files:**
- Create: `scripts/net/mines_table_controller.gd`

**Interfaces:**
- Consume: `MinesTableState` (Task 2/3 completo), `multiplayer.is_server()`, `multiplayer.get_remote_sender_id()`, `multiplayer.get_unique_id()` (API estándar de Godot).
- Produce: nodo `MinesTableController` con señales `state_changed(state: Dictionary)` y `chips_won(player_id: int, amount: int)`, métodos de entrada `start_round(total_cells: int, mine_count: int, amount: int)`, `reveal(index: int)`, `cash_out()`, y `request_state()` — cada método de entrada aplica la acción directamente si es el host, o hace `rpc_id(1, ...)` si es cliente (mismo wrapper que `DiceTableController`). Usado por `MinesTableNet` (Task 5) y por `CasinoFloor` (hook de `chips_won` para la meta colectiva, Task 5).

- [ ] **Step 1: Implementar MinesTableController**

```gdscript
class_name MinesTableController
extends Node

signal state_changed(state: Dictionary)
signal chips_won(player_id: int, amount: int)

var table_state: MinesTableState

func _ready() -> void:
    if multiplayer.is_server():
        table_state = MinesTableState.new()
        table_state.chips_won.connect(_on_table_chips_won)

# Puntos de entrada para la UI local (host o cliente). El host actúa directo
# sobre table_state; un rpc_id(1, ...) a sí mismo lo rechaza el MultiplayerAPI
# ("call_remote" no permite invocarse a uno mismo), así que el host no puede
# pasar por las RPCs request_* para sus propias acciones. Mismo patrón que
# DiceTableController, con tres acciones en vez de una porque la ronda de
# Mines es multi-paso.
func start_round(total_cells: int, mine_count: int, amount: int) -> void:
    if multiplayer.is_server():
        _apply_start_round(total_cells, mine_count, amount, multiplayer.get_unique_id())
    else:
        request_start_round.rpc_id(1, total_cells, mine_count, amount)

func reveal(index: int) -> void:
    if multiplayer.is_server():
        _apply_reveal(index, multiplayer.get_unique_id())
    else:
        request_reveal.rpc_id(1, index)

func cash_out() -> void:
    if multiplayer.is_server():
        _apply_cash_out(multiplayer.get_unique_id())
    else:
        request_cash_out.rpc_id(1)

# Un cliente que entra a la mesa después de que ya hubo rondas no recibe
# nada por su cuenta: el host solo retransmite _receive_state cuando algo
# cambia, nunca al conectar (mismo gotcha que TableController.request_state
# en Plan 3). Sin este pedido explícito el cliente se queda con el estado en
# blanco para siempre.
func request_state() -> void:
    if multiplayer.is_server():
        return
    _request_state.rpc_id(1)

@rpc("any_peer", "call_remote", "reliable")
func _request_state() -> void:
    if not multiplayer.is_server():
        return
    _receive_state.rpc_id(multiplayer.get_remote_sender_id(), table_state.to_dict())

@rpc("any_peer", "call_remote", "reliable")
func request_start_round(total_cells: int, mine_count: int, amount: int) -> void:
    if not multiplayer.is_server():
        return
    _apply_start_round(total_cells, mine_count, amount, multiplayer.get_remote_sender_id())

@rpc("any_peer", "call_remote", "reliable")
func request_reveal(index: int) -> void:
    if not multiplayer.is_server():
        return
    _apply_reveal(index, multiplayer.get_remote_sender_id())

@rpc("any_peer", "call_remote", "reliable")
func request_cash_out() -> void:
    if not multiplayer.is_server():
        return
    _apply_cash_out(multiplayer.get_remote_sender_id())

func _apply_start_round(total_cells: int, mine_count: int, amount: int, player_id: int) -> void:
    if table_state.start_round(player_id, total_cells, mine_count, amount):
        _broadcast_state()

func _apply_reveal(index: int, player_id: int) -> void:
    if table_state.reveal(player_id, index):
        _broadcast_state()

func _apply_cash_out(player_id: int) -> void:
    if table_state.cash_out(player_id):
        _broadcast_state()

func _broadcast_state() -> void:
    _receive_state.rpc(table_state.to_dict())

# Broadcast a TODOS los presentes en CasinoFloor, no solo a quien jugó — la
# spec pide visibilidad compartida de las rondas de los demás aunque nadie
# más participe en ellas. La única información que nunca llega por aquí
# mientras la ronda sigue activa son las posiciones de las minas — eso lo
# garantiza table_state.to_dict(), no este controlador.
@rpc("authority", "call_local", "reliable")
func _receive_state(state: Dictionary) -> void:
    state_changed.emit(state)

func _on_table_chips_won(player_id: int, amount: int) -> void:
    chips_won.emit(player_id, amount)
```

Guardar en `scripts/net/mines_table_controller.gd`. Nota: en el host, `_ready()` crea `table_state` y conecta su `chips_won`; en los clientes queda `null` a propósito — los clientes nunca ejecutan lógica de juego, solo reciben `state_changed`/`chips_won` y piden acciones por RPC.

```gdscript
extends Control

const TOTAL_CELLS := 25

@onready var table_controller: MinesTableController = $TableController
@onready var status_label: Label = $StatusLabel
@onready var mine_count_spinbox: SpinBox = $MineCountSpinBox

@onready var cash_out_button: Button = $CashOutButton
@onready var grid: GridContainer = $MinesGrid

var _cell_buttons: Array[Button] = []
var _last_players: Dictionary = {}

func _display_name(peer_id: int) -> String:
	var steam_id: int = NetworkManager.peer_steam_ids.get(peer_id, 0)
	if steam_id == 0:
		return "jugador %d" % peer_id
	var persona_name := Steam.getFriendPersonaName(steam_id)
	return persona_name if not persona_name.is_empty() else "jugador %d" % peer_id

func _ready() -> void:
	for child in grid.get_children():
		if child is Button:
			_cell_buttons.append(child)
	for i in range(_cell_buttons.size()):
		_cell_buttons[i].pressed.connect(_on_cell_pressed.bind(i))
	table_controller.state_changed.connect(_on_state_changed)
	start_button.pressed.connect(_on_start_pressed)
	cash_out_button.pressed.connect(_on_cash_out_pressed)
	NetworkManager.identities_changed.connect(_refresh_status_label)
	_set_round_ui_active(false)
	# Mismo gotcha que dice_table_net.gd/roulette_table_net.gd: un cliente
	# recién llegado a esta escena puede que aún no tenga el
	# SteamMultiplayerPeer en CONNECTED — bloquear el botón de empezar hasta
	# entonces evita el rpc_id() fallido.
	if not multiplayer.is_server():
		var peer := multiplayer.multiplayer_peer
		if peer == null or peer.get_connection_status() != MultiplayerPeer.CONNECTION_CONNECTED:
			start_button.disabled = true
			multiplayer.connected_to_server.connect(func():
				start_button.disabled = false
				table_controller.request_state()
			)
		else:
			table_controller.request_state()

func _on_start_pressed() -> void:
	table_controller.start_round(TOTAL_CELLS, int(mine_count_spinbox.value), int(amount_spinbox.value))

func _on_cell_pressed(index: int) -> void:
	table_controller.reveal(index)

func _on_cash_out_pressed() -> void:
	table_controller.cash_out()

func _set_round_ui_active(active: bool) -> void:
	start_button.disabled = active
	cash_out_button.disabled = not active
	mine_count_spinbox.editable = not active
	amount_spinbox.editable = not active
	for button in _cell_buttons:
		button.disabled = not active

func _on_state_changed(state: Dictionary) -> void:
	_last_players = state["players"]
	var my_id := multiplayer.get_unique_id()
	if _last_players.has(my_id):
		var my_data = _last_players[my_id]
		var active_round = my_data["active_round"]
		_set_round_ui_active(not active_round.is_empty())
		for i in range(_cell_buttons.size()):
			if not active_round.is_empty() and active_round["revealed"].has(i):
				_cell_buttons[i].text = "X"
				_cell_buttons[i].disabled = true
			else:
				_cell_buttons[i].text = ""
	_refresh_status_label()

func _refresh_status_label() -> void:
	if _last_players.is_empty():
		status_label.text = "Nadie ha jugado todavía."
		return
	var lines: Array[String] = []
	for player_id in _last_players:
		var player = _last_players[player_id]
		var line := "%s — fichas %d" % [_display_name(player["player_id"]), player["balance"]]
		var active_round = player["active_round"]
		if not active_round.is_empty():
			line += " — ronda en curso (%d reveladas, x%.2f)" % [active_round["revealed"].size(), active_round["multiplier"]]
		elif not player["last_round"].is_empty():
			var last_round = player["last_round"]
			var outcome_text := "ganó" if last_round["win"] else "perdió"
			line += " — última ronda %s (%d minas, %d reveladas)" % [outcome_text, last_round["mine_count"], last_round["revealed"].size()]
		lines.append(line)
	status_label.text = "\n".join(lines)
```
